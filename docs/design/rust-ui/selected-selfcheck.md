# selected-workflow.html self-check

Open `selected-workflow.html` standalone (file://) or via html_render. No setup, no network. It replaces the eight-design gallery; `proposals.html` is untouched history.

**Built-in:** footer shows `Prototype self-check: N / N passed` (this revision: **285/285 at 1440 and 1280, 288/288 at 728, 287/287 at 600**, headless Chromium `--dump-dom`). Re-run with `__selfcheck()`; failures are listed in the footer and `console.error`. The check runs on fresh sample fixtures (`fresh()`), never writes real localStorage, and restores the user's edited state and rendered page afterwards.

## Review fixes (workflow-revision-review.md) and their regression checks
- **Provenance (P1):** results are bound to the resolved path they were written to (`made.loc`, `made.ver`). A range change blocks only a re-key into the *same* folder; a manual version/root change permits a fresh run, which archives the earlier results into `prev` (with their paths). `outCheck` and Next free version treat every `prev` path as taken, so typing 1 after writing v002 is blocked. A job that finishes after a location edit stays recorded at its frozen path; Next free version is refused while the clip has a job. A blank custom root stays Custom and invalid (“root is empty”), never inheriting.
- **Functional (P2):** an output that is off or was not written shows no image; `#` in token values becomes `_` and `####` expands before token substitution; VideoMaMa/MatAnyone2 need a subject *and* a background stroke inside In/Out; annotations draw on the Hint channel with no hint and on the Outside In/Out placeholder; I/O/M/K/←/→ work with a plain button focused while Space/Enter/text/select editing stay native.
- **Same-root (P3):** requeue rows agree with the gate (range change offers Write as vNNN, never a refused full Key); requeueing a hint re-links its dependent Key; letterbox clicks are ignored; the hint identity is route + range coverage + the marks a mark-based route used (VideoMaMa/MatAnyone2). **Hint quality is deliberately not part of hint identity:** `backend/service/core.py` documents it as trust in an external hint at inference, so changing it marks Key results stale (existing rule) but does not force hint regeneration; the Hint panel says so. The technical note now says the manifest already records `frame_range` but lacks stem identity, resolved template paths and compression.
- ~36 new checks reproduce each review case (P1-a/b/c, P2-1…6, P3 requeue/hint/letterbox/hint identity/footer note).
